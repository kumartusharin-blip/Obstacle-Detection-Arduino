# Obstacle Detection using Arduino

## 📌 Overview
This project uses an ultrasonic sensor to detect obstacles in front of it. When an object is detected within a certain distance, the system stops or controls the motor accordingly. This project is commonly used in robotics and automation systems.

## ⚙️ Components Used
- Arduino Uno
- Ultrasonic Sensor (HC-SR04)
- DC Motor / Servo Motor
- Motor Driver (L298N or L293D)
- Jumper Wires
- Breadboard
- Power Supply / Battery
- Wheels (for robot car, if used)
- Chassis (optional for robot structure)
- LED (for indication, optional)
- Buzzer (optional alert system)

## 🔌 Working Principle
The ultrasonic sensor sends ultrasonic waves and receives the reflected signal (echo). Based on the time taken for the echo to return, the distance is calculated. If an obstacle is detected within a predefined range, the Arduino sends a signal to stop or change the direction of the motor.
